# Authoritative Metric Continuity

The existing `Rca2Metrics.REQUIRED` inventory contains the authoritative 27 metrics. OP-2 does not change their meaning, unit, SC-6 threshold, P1/P2 mismatch separation, protected-gap classification or zero-tolerance semantics.

Allowed labels remain `environment`, `lane`, `result_class` and `breaker_state` only.
