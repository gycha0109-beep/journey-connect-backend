# Journey Connect Admin UI

Standalone administrator dashboard integrated in the authoritative backend repository.

## Commands

```bash
npm install
npm test
npm run lint
npm run build
npm run verify:adm4
```

The UI uses relative `/api/v1` and `/api/admin` paths by default. Set `VITE_DEV_BACKEND_URL=http://localhost:8080` for the Vite development proxy.
